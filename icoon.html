🐝 Icoon maken

1. Download apple-touch-icon.png 2. Download icon-192.png 3. Download icon-512.png
  1. Tik op de drie knoppen hierboven. De bestanden komen in de app Bestanden, map Downloads.
  2. Ga op GitHub naar je repository, Add file → Upload files, en kies de drie bestanden uit Bestanden.
  3. Tik op Commit changes en wacht op het groene vinkje.
  4. Verwijder het oude icoon van je beginscherm en zet de agenda opnieuw op je beginscherm.
